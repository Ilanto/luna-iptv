# Luna IPTV Implementation Plan

> For agentic workers: use superpowers:subagent-driven-development. Root coordinates integration and verification; independent core/playback tasks run concurrently.

**Goal:** Deliver a working original personal IPTV desktop client and tested openSUSE RPM.
**Architecture:** PySide6 UI consumes pure-Python playlist/EPG/SQLite services. Network workers and libmpv OpenGL rendering stay outside blocking GUI operations.
**Tech Stack:** Python >=3.11, PySide6 >=6.8,<6.12, libmpv >=0.38, SQLite, FFmpeg (QA only), pytest, rpmbuild.
**Spec:** docs/superpowers/specs/2026-09-05-luna-iptv-design.md

## Global constraints
User colors/font and original visual assets only. Runtime requires no browser/server or subscription bundled. No credentials in logs. Real media smoke test required. Source tree is initially empty, so work directly on new luna-client branch. Full plan and implementation already authorized in the user request.

## Task 2: Native playback renderer
Files: luna_iptv/player.py; tests/test_player.py.
Interface: Player(QObject), VideoWidget(player,parent); signals ready(), property_changed(str,object), error(str), file_loaded(), ended(); load(url,headers=None,start=0), command(list), set_property(name,value), pause_toggle(), stop(), shutdown(). Qt owns the render context; GL callbacks schedule work on the GUI thread. Free render context before libmpv teardown.
